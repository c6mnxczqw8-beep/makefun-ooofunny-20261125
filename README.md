# The Funniest Out-of-Office — entry

A program/v1 entry for the make.fun "The Funniest
Out-of-Office" bounty. `main.py` writes one auto-reply line
to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The line:

> I am out of office until Monday. Emails will be read in the order they were regretted.

An auto-reply with a queue discipline, and the discipline is
the joke: every sender immediately starts calculating their
email's position. An earlier deadpan draft ("The office has
been notified") was rejected for risking life as an actual
auto-reply. See `CANDIDATES.md` for the full draft list.
